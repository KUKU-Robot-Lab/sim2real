## 1. 경로

```
정책 행동(손 6) ─ 손 법칙: raw = open + (a+1)/2·(grip−open), EMA 0.1, 스텝 상한(전 범위 1 s)
               ─ 막힘 쥠 멈춤(hand_block): 손가락이 막히면 그 축은 더 닫지 않는다      ← sim · 실기 같은 식
               ─ 쥔 판정 = 엄지 굽힘 래치 AND 손가락 래치(+ GraspHold 유지)          ← lift_hold 멈춤 · 부착이 쓴다
sim  : 지연 4~6 스텝 → 앞섬 상한(실측 ±0.2 rad) → 어드민턴스(정책 주기 60 Hz) → 관절 PD
실기 : pd 노드(앞섬 상한 0.2 rad) → /hand_<s>/angle_target(50 Hz) → C 마스터 어드민턴스(500 Hz)
       → 손 펌웨어 위치 제어(speed 2000 · force 600 g · 전류 800 mA)
```

어드민턴스 식은 둘이 같다(`admittance.py` = `rh56f1_admittance.h` 를 옮긴 것, 값도 같음:
